# ⏳ 订单服务 v2 Review 清单

> 本次 Review 范围：订单创建链路、库存扣减、支付回调处理。
> 目标版本：v2.3.0，上线时间：2024-06-15

## 一、接口层
### 1.1 参数校验
- ✅ userId 格式校验（正则 `^u_\d+$`）
- ✅ items 非空且长度 ≤ 50
- ✅ quantity 范围 [1, 99]
- ⏳ couponCode 格式校验（目前只做非空，未校验字符集）
- ❌ addressId 归属校验缺失，任意用户可使用他人地址 ID
### 1.2 幂等处理
- ✅ X-Idempotency-Key 存在时走幂等逻辑
- ✅ Redis SETNX 写入成功后再执行业务
- ⏳ Key 过期后是否清理映射数据？未见清理逻辑
## 二、业务逻辑层
### 2.1 库存扣减
- ✅ 扣减前加分布式锁（Redisson）
- ✅ 超卖防护：库存 < quantity 时返回 1002
- ❌ 锁粒度为商品级别，高并发热门商品可能成为瓶颈，建议改为 SKU 级别
- ⏳ 锁超时时间 5s，若下游支付服务响应慢，可能导致锁提前释放
### 2.2 优惠券核销
- ✅ 核销前校验优惠券归属用户
- ✅ 核销操作幂等（以 orderId 为唯一键）
- ✅ 核销失败时回滚库存
- ⏳ 优惠券最低消费门槛校验逻辑在客户端，服务端未做二次校验
### 2.3 价格计算

| 校验项 | 结论 |
| --- | --- |
| 商品现价与快照价差值 > 5% 时拦截 | ✅ 已实现 |
| 运费计算逻辑 | ✅ 已实现 |
| 满减活动叠加计算 | ❌ 叠加逻辑有误，见 Issue #234 |
| 积分抵扣上限 | ⏳ 逻辑待确认 |
